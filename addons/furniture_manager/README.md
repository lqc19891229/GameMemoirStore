# 家具资源管理器（Godot 编辑器插件）

这是一个用于**开发阶段**的小型家具资源浏览面板。它直接读取现有 `data/items/_catalog.tres`，不建立第二套商品数据库，也不修改 `item_id`、实例 UID 或玩家存档。

## 打开方式

使用 Godot 4.6 打开项目，编辑器底部选择 **家具资源**。插件已在项目的 `[editor_plugins]` 启用；若未显示，可在 **项目设置 → 插件** 中启用 Furniture Resource Manager。

## 功能

- 搜索家具名称、`item_id` 和说明文字。
- 按现有一级分类筛选，包含“显示停用”选项。
- 显示家具中文名称、类别、商品 ID、资源检查结果。
- 检查缺少 ID、名称、摆放角色、无效商品类型、缺少或没有独立路径的家具场景、重复商品 ID。
- 点击 **在检查器中编辑商品**，直接编辑现有 `MemoirItemDefinition` 资源。
- 点击 **打开家具场景**，进入该家具的 `.tscn`。
- 修改原始商品目录或文件后，点击 **刷新** 重新读取。
- **3D 预览**：选中家具时，在隔离的 SubViewport 中实例化该场景；可通过左右按钮转动查看。
- **几何尺寸**：根据实际 MeshInstance3D 可视网格估算包围尺寸，单位米；这不是碰撞体或承载面尺寸。
- **摆放边界（橙色）**：读取家具根节点的 `bounds`，在 3D 预览中用线框显示房间编辑器定义的占用范围，可以开关。
- **承载面（绿色）**：读取 `support_surfaces` 中已经注册的桌面和书架锚点，在预览中绘制绿色矩形并列出每个锚点的 ID、长宽、离地高度。没有承载面元数据的家具不会凭空推断可摆放区域。
- **数据对照**：详情同时展示实际网格尺寸、布置边界尺寸与承载面列表，方便发现模型与配置的不一致。
- **模型定位**：尝试查找场景中引用的 GLB/GLTF 模型文件，显示来源路径并提供在文件系统面板中定位的按钮。纯 Godot 原生网格场景不一定有外部模型路径。

## 数据规则

1. `data/items/_catalog.tres` 是唯一商品目录，不向其他 JSON 或 TRES 复制内容。
2. `MemoirItemDefinition.furniture_scene` 仍关联实际 `PackedScene`。
3. 商品分类用 `scripts/items/item_taxonomy.gd`，不根据“工作区／游戏区／休息区”等房间用途分类。
4. 在 Inspector 中修改商品后，按 Godot 的资源保存流程保存项目更改；面板本身不会自动写盘。
5. **当前版本支持资源浏览、3D 预览及检查**，不包含导入 GLB、批量修改、自动创建家具或存档迁移功能。
6. 3D 预览只使用一个按需加载的 SubViewport；不会修改玩家房间，也不会给每件商品创建常驻渲染视口。

## 边界与承载面的含义

橙色线框是已有的家具 `bounds` **摆放阻挡尺寸**，并不等于物理引擎中 `CollisionShape3D` 的精确几何；绿色矩形来自当前家具已经声明的 `support_surfaces` 元数据。绿色代表可承载物体的候选平面，不会改变游戏里的摆放规则。

## 承载面编辑与保存

1. 在家具资源管理器选择书架或桌子，按 **「打开家具场景」**，确保选中的独立家具场景是当前正在编辑的 Godot 场景。
2. 在面板 **「承载面编辑」** 列表选择锚点，调整 ID、中心 X/Y/Z、宽度 X 和深度 Z，点击「更新所选」。也可以新增或删除锚点。
3. 预览中的**绿色线框**跟随待保存的编辑数值变化，但此时不会修改原始家具场景，也不会修改玩家房间。
4. 点击 **「应用并保存当前家具场景」**。插件核对当前编辑场景路径，再通过 Godot 编辑器的 Undo/Redo 操作写入场景根节点的 `use_custom_support_surfaces` 和 `custom_support_surfaces` 导出字段，并调用 Godot 保存场景。
5. 在 Godot 中可以撤销本次编辑；若使用撤销，需重新保存场景以持久化撤销结果。

兼容性：原始场景若没有启用自定义承载面，继续按旧 `room_furniture.gd` 逻辑生成书架、边桌等默认承载面。首次应用才启用自定义承载面；**保存空列表表示主动取消全部可承载区域**，不是恢复默认规则。已有存档的物品 ID、家具 UID 和摆放数据不变化。

安全限制：插件不重新打包 `PackedScene`，不会破坏模型实例层级；只支持有 `apply_custom_support_surfaces` 方法的家具根节点，不能直接编辑导入的 GLB 场景或无相关组件的独立场景。锚点会校验唯一 ID、有效坐标、正尺寸和最多 32 个条目。功能聚焦数值配置与实时预览，不支持在 3D 视口里拖拽锚点。


## 3D 预览拖动承载面

管理器中选中支持承载面的家具，绿色承载面线框将突出显示当前选中的层；也可以点击右侧承载面列表切换。

- **拖动矩形中央黄色十字**：沿 X/Z 平面移动该承载面，原有 Y 高度保持不变。
- **拖动矩形四边中点黄色十字**：分别改变 X 方向宽度或 Z 方向深度，另一侧边缘保持固定。最小宽度/深度为 0.02 米。
- 编辑结果按 0.01 米步长吸附，列表中的数值立即同步；仍可用数字框精确修改高度和尺寸。
- 拖拽仅改变**预览草稿**，不会即时修改场景、商品资源或玩家房间；确认结果后仍需点击「应用并保存当前家具场景」。
- 若关闭绿色「承载面」显示开关，3D 拖拽也会关闭。视角可以用原来的左右旋转按钮调整。

本交互使用当前预览相机到原有承载面高度的平面射线求交，不按网格法线猜测规则，不支持曲面承载面或在预览里调整 Y 高度。已有独立场景的保存与编辑器撤销流程保持不变。
