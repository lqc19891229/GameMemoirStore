# P42 补充 · 默认房间的木纹、窗帘与天空渐变

本补充在 **P42 原有场景光影与窗景升级（PR #69）** 已合并的基础上完成，明确保留它的 `WindowBounce`、`WarmCoveFill`、天气驱动的 `ExteriorWindows` 和 `WindowSillApron` / `WindowSillHighlight`。不再重复创建建筑立面灯光或窗台盖板。

## 改进内容

| 部位 | P42 补充效果 | 兼容要求 |
| --- | --- | --- |
| 默认橡木地板 | 128×128 确定性双频木纤维纹理，微小孔隙和低对比度亮暗，mipmap 与过滤 | 保留旧默认地板基色、行间色差、自定义楼板分区、墙面/地板 0–2 图样和所有存档字段 |
| 两片亚麻窗帘 | 从平面方盒换成带 UV、法线的真实褶皱曲面，各片 10×32 面细分；织物纹理、上沿、底部垂边和金属挂钩 | 同一窗户尺寸，`CurtainHem` 历史节点名称继续存在；无 CollisionObject3D / 物体拾取，跟随左墙剖切 |
| 窗外天空 | 128×128 柔和渐变/薄云的可复用灰阶贴图，由现有 `WindowSky.albedo_color` 按晴昼、日落、夜晚、雨天着色 | 原 P42 的夜间窗灯、暖色反弹光和雨景继续按照已有逻辑工作 |

本阶段不增添任何新的家具编辑操作、批量布置、库存限制、创意工坊和作品存档功能。

## 纹理性能约束

- 默认地板纹理由 `room_view.gd` 原有缓存复用，蓝图重建后各块铺板重用同一图样。
- 亚麻及窗景纹理只在每个房间实例第一次构建时生成，蓝图重建时再次复用。
- 窗帘三维网格共 2 片，只用于视觉，不创建新的射线命中区、物理体或实时阴影灯。
- 沿用项目 Godot 4.6 Compatibility 渲染器，不引入 SSR / SSIL / 体积雾。

## 自动与人工验收

`tests/life/test_room_art_direction.gd` 检查低对比度木纹、mipmap、两片窗帘 UV/法线、织纹与挂钩、天空渐变、四种天气、原 P42 夜窗灯、蓝图重建、墙体剖切、库存/布局不变等。另保留 `test_room_cinematic.gd` 对 PR #69 的补光及原始窗台节点检查。

项目 CI 会运行 Xvfb 窗口并生成 **modern-room-preview** 截图 artifact；自动化数据检查不替代最终在目标 PC 分辨率下对颜色、阴影、景深与材质的人工画面评价。
