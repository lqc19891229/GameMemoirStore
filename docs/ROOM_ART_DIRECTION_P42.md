# P42 · 房间美术统一：木纹、织物与窗景

## 定位与边界

本轮从“增加编辑器功能”转向“完善一间房的成品观感”。不增加批量家具摆放功能、不改家具购买/库存 UID、不增加存档字段、不改变相机默认视角、房屋尺寸或可放置范围。P42 的重点是**默认房间即使只摆几件家具也有自然的材质和室内氛围**。

此阶段只针对现有 Godot Compatibility 渲染器下的房间建筑环境。光照和四种天气使用 `MemoirRoomView` 现有的数据与参数，不引入 Forward+ 专用 SSR、SSIL 或体积雾。

## 视觉改善

| 部位 | 改善 | 一致性约束 |
| --- | --- | --- |
| 默认橡木地板 | 从纯色改为 128×128 确定性生成的细木纹：多层木纤维、克制的明暗变化、mipmap 与三线性过滤 | 继续使用现有地板基色、四种行间明度和 0/1/2 纹理切换；自定义蓝图地板与局部改色不丢失 |
| 窗帘 | 两片带真实法线和 UV 的褶皱布片（每片 10×32 面细分）；亚麻经纬纱纹理、垂边、上沿和 8 个挂钩 | 保留原始窗宽、门窗开口、镜头墙体剖切规则；不增加碰撞/拾取节点 |
| 窗台 | 增加薄木质上盖和外沿，保留原本窗台体量 | 所有几何都是视觉子节点，不改变蓝图墙面 ID |
| 窗外背景 | 用 128×128 过滤后的柔和天空明暗纹理代替平涂天空，给三组远景楼体添加小窗格 | 天空色仍受晴昼、日落、夜晚、雨天四种原有风格值控制，雨天窗外雨丝不受影响 |

## 实现与性能

- **资源复用**：每个房间实例只生成并缓存一张默认地板纹理、一张窗帘织物纹理和一张窗外天空渐变纹理，蓝图重建时复用；已有纹理类型仍通过 `room_view.gd` 的缓存管理。
- **程序化网格**：窗帘由轻量 `SurfaceTool` 三角形生成 UV 与法线，仍由原有 `Left_Wall` 父节点统一显示/隐藏。每片没有碰撞体，也不会参与光标命中或布局扫掠。
- **材质**：保留 `StandardMaterial3D` 的现代轻写实粗糙度，不将所有木材和布料改为同一种颜色；新图样使用低对比度与 mipmap，避免默认镜头距离出现像素锯齿。
- **兼容性**：`workstation_layout`、`placements`、`furniture_colors`、`room_style` 和蓝图数据结构均不改动。房间 3D 拾取、墙体剖切、天气和旧存档仍照原有代码工作。

## 自动验收

`tests/life/test_room_art_direction.gd` 与原有全量回归核对：

1. 默认橡木地板有 128×128 的确定性细木纹，并且有 mipmap、线性过滤；三种地板图样和墙纸切换后还能还原原始材质。
2. 两片窗帘是三维网格，拥有实际法线、UV、亚麻纹理、垂边和挂钩，但没有碰撞层，不干扰家具选择。
3. 窗外天空有渐变，四种天气仍能切换天空色，雨丝只在雨天出现。
4. 重新应用蓝图后材质与窗景仍正确、没有重复网格；墙体剖切继续隐藏整个窗户子树。
5. 家具姿态、拥有库存、存档字段及原有 UI/鼠标交互回归全部保持。

完整 CI 还会运行 **Xvfb** 真实图形窗口并上传 `modern-room-preview.png`。该图是方便人工评审的渲染证据，自动回归本身不等同于最终审美验收。后续正式美术资产和统一画质仍须在实际目标分辨率下目测。
