# P23 房间光影与镜头

## 光影方案

本项目仍采用 Godot 4.6 的 **Compatibility** 渲染器，不启用 Forward+ 独占的屏幕空间反射 SSR 或间接光照 SSIL。

- **室内材质反射**：在保持原有无缝纯色背景的同时，为 Environment 提供独立的 ProceduralSkyMaterial 天空辐射反射。晴昼、日落、夜晚、雨天四个气氛预设有不同的顶光、地面与地平线反射色。
- **柔和阴影**：KeyLight 使用方向阴影分层混合和柔化参数；日落时降低光照角度，夜晚和雨天降低阴影不透明度、提高柔和程度，避免在 P22 新增倒角处产生粗黑阴影。
- **材质层次**：启用温和的 SSAO 接触阴影和 Filmic 高光压缩。原有粗糙度和金属度仍由 GLB/PBR 管理；不向玩家资产烘焙固定阴影。
- **性能**：辅助 FillLight 不生成阴影；不引入全局实时反射探针、SSIL、SSR 或昂贵的体积雾。环境天空资源在房间实例间独立复制，切换天气不影响其他场景。实际效果仍取决于图形驱动及 Compatibility 的渲染能力。
- **旧存档**：继续沿用已有的 `room_style.atmosphere` (0–3) 和 `light` 等参数，没有增加存档字段。原先测试期望的默认主光能量 0.75 保持不变。

## 镜头操作

进入房间编辑器，选中一件已摆放家具，按 **F** 可用 0.30 秒柔和动画让镜头对准家具中心；滚轮缩放和鼠标环绕继续以新中心运动。点击顶部「重置视角」回到作者设定的原始相机位置、朝向与环绕中心。

聚焦仅修改相机，不移动家具、不记录到撤销栈、不写入存档。正在预览新家具时、蓝图模式或电脑屏幕模式时不会触发。编辑器搜索栏正在输入文字时不会拦截 F。

## 自动化验证

`tests/life/test_room_cinematic.gd` 检查天空、四种气氛、阴影/曝光/环境遮蔽，以及镜头 F 聚焦、复位和存档不变。原有光照和电脑屏幕点击测试继续保留。
