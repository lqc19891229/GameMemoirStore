# 项目检查与场景整理

检查日期：2026-10-31。环境：Godot 4.6 stable、Compatibility / Mesa OpenGL、Python 3.12、Blender 3.6.23 LTS。

## 检查结论

40 个场景已按功能迁移，主入口与所有已知的静态、动态加载路径同步更新。Godot 导入和全部自动检查通过。资源扫描未发现缺失引用、重复 UID、孤立导入配置、完全重复素材或未引用的场景 / 素材候选。

本次没有发现可以直接删除的正式场景或素材。旧目录中的场景全部迁移，不保留旧路径副本；目录说明重新归类，空的旧场景目录已清理。测试样本、旧演示封面、Blender 源文件和历史存档兼容数据都有用途，继续保留。

## 已修复的问题

| 问题与触发方式 | 修复 |
|---|---|
| 当前 Excel 已启用两款作品，旧检查仍固定为一款，并假定数据从第 4 行开始，导致 5 项断言失败 | 资源检查遍历当前目录；导入器测试按 ID 查找 CounterSquad，并校验整份生成目录与 Excel 一致，不再固定行号、游戏数量和截图分辨率 |
| 商城截图命令仍使用已退出正式目录的 distant_signal 等 ID，商品页为空、购物车和游戏库预览不完整 | 预览使用当前可购买目录；愿望单预览重复调用不会反向取消已有条目 |
| 单独运行购物网页，点击“购物 / 我的物品”会访问空 session 并报错 | 缺少共享会话时保留场景示例内容，标签操作不执行交易刷新 |
| 移动、旋转或缩放 ComputerDesktop 根节点后，屏幕镜头将世界坐标直接当作局部坐标，导致取景偏移 | 镜头目标转换到相机父节点的局部坐标；验证了变换后的投影和输入映射 |
| 绕到显示器背后点击时，射线仍能命中屏幕平面并进入系统 | 屏幕输入增加正面朝向判定 |
| 存档的钱包、月份、版本、历史或活动数值被写为数组 / 字典时，直接 int 转换会使加载中断；过大数值也有转换风险 | 转换前检查数值类型和有限性并限幅；异常字段回退，正常所有权等资料继续保留 |
| 电脑、商城、网页和专用组件混放，目录说明与实际结构不符 | 按功能迁移 40 个场景，更新配置、脚本、测试、文档和动态模板路径 |

编辑器检查改为递归遍历全部场景，覆盖原先遗漏的 5 个平台弹窗 / 菜单场景。

新增 `tests/life/test_audit_regressions.gd`，覆盖上述预览、屏幕与存档回归；新增 `tools/project_audit.py`，便于再次检查路径、UID、导入配置、GLB 外部依赖和资源冗余候选。

## 文件保留依据

- `tests/fixtures/` 的十二款旧游戏资源和表格行：交易、筛选、存档迁移与导入器检查的固定样本，不加入正式目录。
- `assets/art/` 中的旧演示封面及 `data/catalog.json`：固定样本仍引用，用于评价、折扣和展示回归。
- `tools/models/hardware.blend` 与建模脚本：9 个 GLB 的可编辑来源；已确认 Blender 源文件可打开，GLB 无外部缓冲 / 图片依赖。
- `.gd.uid`、图片和 GLB 的 `.import`：Godot 资源身份与导入设置，检查未发现孤立文件或重复 UID。
- 字体授权、资源制作说明和项目文档：保留来源、使用和编辑依据。
- 历史家具、展示和布局数据：用于兼容旧存档，不重新生成房间场景。
