# GameMemoirStore 美术风格设计规范

**文档版本：** 1.0  
**适用项目：** GameMemoirStore  
**引擎基线：** Godot 4.6  
**参考方向：** My Dream Setup  
**目标风格：** 现代、温馨、整洁的轻写实 3D 房间与电脑桌搭

> 本文定义项目未来的视觉方向和资源制作标准。My Dream Setup 仅作为空间氛围、房间布置和桌搭展示的方向参考；项目应建立自己的模型、材质、界面和视觉识别，不直接复制其美术资产或具体设计。

---

## 1. 美术定位

### 1.1 核心目标

GameMemoirStore 从像素风格转向现代轻写实 3D 房间布置风格。

核心体验是让玩家逐步购买电脑设备、收集家具、布置空间、调整灯光，最终打造一个具有个人审美的理想游戏房间。

**视觉关键词：**

- Cozy：温馨、舒适、有生活气息
- Modern：现代、简洁、功能清晰
- Clean：整洁、克制、视觉层级明确
- Aesthetic：桌搭与室内装饰具有审美感
- Stylized Realism：比例可信、细节适度的风格化写实
- Soft Lighting：柔和自然的室内光照
- Gaming Setup：电脑设备与桌面布置是视觉重点

### 1.2 风格边界

采用轻写实、适度风格化的 3D 表现，不追求照片级写实，也不使用夸张卡通比例。

| 维度 | 目标 |
|---|---|
| 模型 | 中低至中等复杂度，轮廓完整、比例可信 |
| 比例 | 以真实家具、房间和电子设备尺寸为依据 |
| 材质 | 以 PBR 工作流为基础，控制粗糙度和反射 |
| 纹理 | 清晰、自然，避免像素化和过度锐化 |
| 光照 | 自然光、柔和主光、局部装饰光 |
| 色彩 | 低饱和基础色，少量高饱和点缀 |
| 阴影 | 柔和且稳定，避免过黑或锯齿明显 |
| 后处理 | 适度环境遮蔽、色调映射和 Bloom |
| UI | 现代简洁、清晰、统一的桌面应用风格 |

### 1.3 明确不再使用的表现

- 像素化画面滤镜和低分辨率 RenderTexture 采样
- 颜色量化、像素网格化和刻意低分辨率显示
- 为像素风格制作的块状纹理和粗糙边缘
- 像素字体、像素边框和复古像素 UI

移除旧效果时，应先确认场景引用、脚本依赖和屏幕显示路径，再逐步停用和清理；不能只按名称批量删除资源。

## 2. 整体视觉与色彩体系

### 2.1 空间氛围

房间是项目最重要的展示场景。玩家进入房间时应感受到：

1. 空间比例可信，家具摆放符合日常使用习惯。
2. 环境干净、舒适，但不是空洞的样板间。
3. 电脑设备具有展示和收藏价值。
4. 光线能够表现白天、黄昏和夜晚的情绪差异。
5. 玩家布置前后的视觉变化明显，容易产生完成感。

### 2.2 基础色板

以低饱和中性色为主：

| 用途 | 建议色系 |
|---|---|
| 墙面 | 暖白、米白、浅灰、淡灰绿 |
| 地板 | 浅橡木、自然木色、胡桃木、灰木色 |
| 桌面 | 原木、白色、深胡桃木、哑光黑 |
| 家具 | 米白、浅灰、炭灰、原木色 |
| 金属 | 银灰、枪灰、哑光黑 |
| 布艺 | 米色、奶油色、浅灰、低饱和蓝绿 |
| 装饰 | 薄荷绿、雾蓝、淡粉、柔和紫色 |

强调色可以使用天蓝、薄荷绿、柔和紫色、淡粉和暖橙。RGB 灯光允许更高饱和度，但应控制照射范围和亮度。

建议把“80% 基础中性色、15% 辅助色、5% 强调色”作为构图参考，而不是硬编码限制。

### 2.3 色彩验收

- 同一房间中墙面、地板、桌面和家具不能互相抢色。
- 大面积表面避免纯白和纯黑造成的细节丢失。
- RGB 不能替代正常环境照明。
- 不同时间预设要有明确区别，但不能改变模型本身的材质颜色。

## 3. 房间与建筑结构

### 3.1 房间结构

当前房间系统应逐步从简单展示盒升级为完整的现代室内空间。

基础构件：

- 墙壁、地板和天花板
- 门、窗户和窗框
- 窗帘、百叶窗或遮光帘
- 踢脚线、墙角收边
- 室内主灯和局部灯具
- 墙面挂画、壁架和装饰

后续扩展：

- 多种房间户型和面积
- 不同墙面与地板材质
- 窗外景观
- 墙面装饰系统
- 可更换门窗和照明设施

房间几何、碰撞、家具可放置区域和摄像机遮挡规则必须保持一致。

### 3.2 房间尺寸

继续以真实尺寸作为建模和布置基准。当前房间为 8 × 6 米，桌面约 4.8 × 2.3 米，桌面高度约 0.78 米。

如未来调整尺寸，必须同步更新：

- 场景几何
- LayoutEditor 房间边界
- 家具占地和碰撞尺寸
- 桌面设备放置区域
- 摄像机范围和遮挡规则
- 相关自动化测试

不得只缩放模型而保留不匹配的碰撞范围。

## 4. 家具模型规范

家具是房间布置和收集玩法的核心资产。

| 类别 | 设计要求 |
|---|---|
| 桌子 | 现代桌搭风格；木质、金属、升降桌等款式 |
| 椅子 | 符合人体工学；区分办公椅、电竞椅和休闲椅 |
| 书架 | 现代收纳结构，支持书籍和装饰摆件 |
| 落地灯 | 造型简洁，灯罩和灯杆材质明确 |
| 地毯 | 有织物纹理、包边和不同尺寸 |
| 绿植 | 叶片和花盆有自然差异 |
| 床与床头柜 | 现代卧室家具，比例符合房间尺度 |
| 沙发 | 布艺或皮革材质，表现柔软体积 |
| 收纳柜 | 展示柜、抽屉柜和开放式置物架 |
| 装饰品 | 书籍、相框、模型、手办、钟表和小摆件 |

### 4.1 建模要求

- 关键边缘添加适当倒角，避免所有边缘都像锐利的 CAD 模型。
- 结构细节应符合物品实际用途。
- 不通过夸张比例制造可爱感。
- 近距离可见区域应有足够细节，远距离装饰可简化。
- 同一系列家具应共享设计语言、材质和尺寸逻辑。
- 家具必须提供独立碰撞区域、占地尺寸和放置锚点。

### 4.2 家具功能约束

每件家具应记录：

- 稳定资源 ID
- 模型资源路径
- 实际宽、高、深
- 碰撞和占地边界
- 放置类型（地面、桌面、墙面等）
- 允许旋转的轴
- 是否允许复制
- 是否允许与其他家具重叠
- 交互和展示锚点

替换模型时应保持现有布局数据兼容；如果模型尺寸变化，需要明确迁移或校准方案。

## 5. 电脑设备设计规范

电脑设备是项目最重要的可收集和升级内容之一，应比普通装饰拥有更高的模型与材质精度。

### 5.1 显示器

支持不同尺寸、比例和支架结构：

- 现代窄边框显示器
- 不同尺寸与分辨率定位的型号
- 曲面显示器
- 双屏和多屏组合
- 不同支架、底座和屏幕外壳材质

屏幕必须继续承载实际桌面、游戏平台、购物网页和游戏内容，不能退化为静态贴图。屏幕表面应控制反射，确保 UI 可读。

### 5.2 电脑主机

重点表现：

- 机箱外壳和侧透玻璃
- 主板、显卡、内存和散热器
- 风扇、冷排和水冷管路
- 电源仓、线缆和内部结构
- RGB 灯带和风扇灯效

不同等级的机箱应有明确的外观差异。入门型号可以采用封闭式外壳；高端型号可以采用侧透玻璃、多风扇、水冷和更精细的内部结构。

### 5.3 键盘和鼠标

键盘可覆盖全尺寸、87 键、75% 配列、机械键盘、低矮键盘和 RGB 款式。应表现键帽高度、键盘外壳、旋钮、连接线或无线接收器等差异。

鼠标可覆盖办公、游戏、无线和高端 RGB 款式。重点表现外壳曲线、按键、滚轮、侧键和材质。

### 5.4 其他桌面设备

后续可增加：

- 麦克风和麦克风支架
- 耳机和耳机架
- 桌面音箱
- 摄像头
- 游戏手柄
- 音频接口
- 显示器支架
- 桌面充电设备

设备应能在房间中独立展示，并与设备目录、购买、安装和存档系统关联。

## 6. 材质与纹理规范

### 6.1 PBR 材质

使用 Godot StandardMaterial3D 或兼容的 ShaderMaterial，按需使用：

- Base Color
- Metallic
- Roughness
- Normal
- Ambient Occlusion
- Emission

材质需要体现木材、金属、塑料、玻璃、布料、皮革和橡胶的差异。避免所有物品都使用相似的高光和粗糙度。

### 6.2 材质参考

| 材质 | 表现要求 |
|---|---|
| 木材 | 自然木纹、适度粗糙度、方向合理 |
| 金属 | 金属反射和清晰但不过强的高光 |
| 塑料 | 哑光或半光泽，避免廉价塑料感 |
| 玻璃 | 透明度、反射和厚度合理 |
| 布料 | 细腻纹理、柔和高光 |
| 皮革 | 低强度纹理和柔和反射 |
| 橡胶 | 低反射、较高粗糙度 |
| 屏幕 | 自发光显示，少量反射，不影响可读性 |

### 6.3 纹理尺寸建议

以下为制作起点，最终应根据模型屏幕占比、UV 密度和平台性能调整：

- 小型装饰：512 或 1024
- 普通家具和设备：1024 或 2048
- 近景重点展示模型：按实际需求使用更高分辨率
- 重复使用的木材、布料和金属纹理优先共享

避免无意义的超高分辨率纹理和重复材质副本。

## 7. 灯光与环境

### 7.1 光照构成

采用分层光照：

1. 环境光：提供整体基础亮度。
2. 主光源：模拟窗户自然光或室内主灯。
3. 局部辅助灯：台灯、落地灯、壁灯等。
4. 屏幕发光：显示器和其他屏幕的局部贡献。
5. 装饰灯光：RGB、灯带和小型氛围灯。

灯光应柔和、稳定，避免阴影过黑、过硬或产生大量无意义的动态光源。

### 7.2 时间氛围预设

| 模式 | 光照特点 |
|---|---|
| 清晨 | 偏冷的自然光，亮度逐渐提高 |
| 白天 | 中性、明亮、通透 |
| 黄昏 | 温暖的橙色自然光和柔和阴影 |
| 夜晚 | 较暗的环境光，暖色室内灯与屏幕冷光形成对比 |

未来可扩展为连续时间变化，但第一阶段优先完成可控的静态预设。

### 7.3 RGB 灯光

RGB 是桌搭装饰的一部分，不应成为唯一视觉重点。

支持：

- 常亮、呼吸、彩虹循环
- 自定义颜色和亮度
- 机箱风扇、键盘、鼠标灯光
- 显示器背光和桌底灯带
- 根据设备型号显示对应灯效

发光材质与实际照明必须分开管理。不要为每颗 RGB 灯珠创建独立动态灯光；优先使用发光材质，少量辅助灯负责环境照明。

## 8. 摄像机与场景展示

### 8.1 默认视角

使用第三人称斜俯视角，确保玩家能看到房间布局、桌面设备和家具关系。

保留：

- 房间总览
- 摄像机旋转和缩放
- 桌面近景
- 设备特写
- 家具选中视角
- 布置模式
- 电脑屏幕操作模式

### 8.2 镜头表现

镜头移动应平滑，避免突然跳转。进入电脑操作模式时应清晰看到屏幕内容；返回房间时应恢复合理的观察角度。

### 8.3 展示模式

后续增加独立的房间展示模式：

- 隐藏编辑 UI
- 自由观察或切换镜头预设
- 近景展示设备和家具
- 截图和摄影模式
- 房间布置分享

## 9. UI 美术规范

### 9.1 整体风格

UI 与现代 3D 房间保持一致：

- 圆角面板
- 清晰的文字层级
- 轻量阴影和细边框
- 统一图标风格
- 适当留白
- 避免厚重装饰和过多渐变

不再使用像素字体、像素边框和复古像素 UI。

### 9.2 UI 配色

主要使用白色、浅灰、深灰、深蓝和浅蓝。房间展示界面可使用半透明深色面板，但必须保证文字对比度。

### 9.3 布置模式

布置 UI 应包括：

- 家具分类和物品列表
- 物品详情、尺寸和材质
- 颜色选择
- 移动、旋转和吸附工具
- 应用、取消和恢复默认
- 清晰的选中轮廓与操作手柄

UI 不应遮挡过多房间内容，选中状态必须清楚但不能过度发光。

### 9.4 设备商城

商城应突出设备展示：

- 3D 模型预览
- 型号、价格和性能参数
- 外观与材质差异
- 购买、已拥有和已安装状态
- 安装到房间后的实际效果

## 10. 动画与交互

交互动画应自然、轻量，服务于操作反馈。

| 操作 | 建议表现 |
|---|---|
| 选择家具 | 柔和轮廓高亮 |
| 拾取家具 | 轻微抬起 |
| 移动家具 | 平滑跟随，避免明显延迟 |
| 放置家具 | 轻微落下或吸附反馈 |
| 旋转家具 | 平滑旋转 |
| 安装设备 | 设备模型平滑切换 |
| 开启电脑 | 屏幕逐渐点亮 |
| RGB 灯光 | 颜色和亮度平滑变化 |
| 打开应用 | 窗口平滑展开 |

避免过度弹跳、夸张缩放和卡通式动画。动画不得妨碍快速布置和精确操作。

## 11. 渲染与性能规范

### 11.1 渲染迁移原则

目标是完整分辨率的现代 3D 渲染。

需要逐步停用和移除旧像素化表现，包括 PixelPass、低分辨率采样和颜色量化。

迁移顺序：

1. 记录当前房间、桌面和 UI 的渲染依赖。
2. 在测试分支停用 PixelPass，恢复正常分辨率。
3. 检查抗锯齿、阴影、材质和屏幕显示。
4. 确认电脑操作 UI 不受影响。
5. 完成测试后再清理不再使用的像素化资源。

当前项目使用 Godot Compatibility 渲染器。是否升级 Forward+ 应单独评估目标平台、显卡支持、材质兼容和实际性能；不能把切换渲染器作为美术改造的前置条件。

### 11.2 性能目标

以 PC 为主要平台，目标为普通房间和常见布置下稳定 60 FPS。复杂房间应通过性能测试确认，不以单一静态场景推断性能。

优化方向：

- 控制实时阴影灯数量
- 共享材质和纹理
- 合理使用实例化
- 远距离模型使用 LOD
- 按视野管理物体可见性
- 控制透明材质和高成本后处理
- 避免大量动态 OmniLight3D
- 对大型家具和设备进行性能采样

### 11.3 资源格式

- GLB：3D 模型及嵌入式材质资源
- PNG / WebP：纹理、展示图和 UI 图片
- SVG：图标源文件（导入后按需要栅格化）
- TRES：Godot 材质、资源和配置
- Blender 源文件：需要继续编辑的模型源资产

模型应有合理的实际尺寸、原点、朝向、碰撞边界和材质命名。

## 12. 项目改造路线

改造原则：**先建立视觉基准，再替换核心模型，最后扩展内容。**

不在同一次变更中重写玩法、存档和全部资源。

### 阶段一：取消像素风格

优先级：最高。

工作内容：

1. 检查 PixelPass 和低分辨率渲染链路。
2. 停用像素化采样和颜色量化。
3. 恢复正常分辨率。
4. 调整抗锯齿、阴影和环境光。
5. 检查桌面 UI 和显示器屏幕。
6. 统一相机和房间展示效果。

验收标准：

- 房间不再有像素化效果。
- 家具和设备边缘清晰平滑。
- UI 清晰且可操作。
- 电脑屏幕内容正常。
- 家具布置和设备更换功能正常。

### 阶段二：制作视觉样板间

优先级：最高。

先完成一个完整、可运行的房间样板：

1. 房间外壳和地板
2. 桌子和椅子
3. 显示器、机箱、键盘、鼠标
4. 基础灯光
5. 地毯、绿植和落地灯
6. 一套完整材质和配色

验收标准：

- 整个房间风格统一。
- 总览和近景都能达到目标质量。
- 模型比例、碰撞和放置位置正确。
- 白天和夜晚的灯光效果明确。
- 性能达到项目目标。

样板间通过验收后，才以它作为后续模型和家具制作标准。

### 阶段三：替换和扩展核心模型

优先级：高。

建议顺序：

1. 房间外壳
2. 桌子
3. 显示器
4. 电脑机箱
5. 键盘和鼠标
6. 椅子
7. 书架
8. 落地灯
9. 地毯和绿植

替换模型时保持资源 ID、场景节点接口、设备映射、碰撞逻辑和存档布局兼容。需要改变接口时，必须同步修改脚本和测试。

### 阶段四：灯光与环境升级

优先级：高。

- 建立新的室内主光源
- 优化环境光和窗户自然光
- 增加清晨、白天、黄昏和夜晚预设
- 重新设计 RGB
- 调整阴影、反射和后处理
- 验证复杂灯光下的性能

### 阶段五：房间装饰扩展

优先级：中。

增加床、沙发、窗帘、挂画、壁架、台灯、收纳柜、墙面装饰和桌面摆件。支持更多家具组合和房间主题。

### 阶段六：展示体验

优先级：中。

增加自由摄影机、截图、房间展示模式、镜头预设、设备特写和房间分享。

## 13. 现有功能保护

美术升级不能破坏已有玩法、存档和编辑系统。

必须保留：

1. 玩家钱包和存档
2. 游戏购买、安装和游玩记录
3. 玩家六项能力
4. 直播、攻略和收入系统
5. 电脑设备购买和更换
6. 家具选择、移动和旋转
7. 家具复制、删除、撤销和重做
8. 房间外观和 RGB 设置
9. 旧版本存档兼容
10. 电脑屏幕和应用窗口系统

### 13.1 资源替换保护

- 不因模型替换而删除存档字段。
- 不随意修改家具和设备的稳定 ID。
- 不依赖模型节点名称以外的隐式结构；必要节点应有明确接口。
- 模型尺寸改变时同步更新碰撞和占地。
- 更换设备模型后验证购买、安装、卸载和存档恢复。
- 删除旧资源前先搜索全部场景、脚本、资源和测试引用。
- 不自动覆盖尚未审核的 GLB 生成结果。

## 14. 美术质量验收

每个新增或替换模型都必须经过以下检查：

| 检查项 | 验收标准 |
|---|---|
| 风格一致性 | 符合现代轻写实风格 |
| 比例 | 接近真实物品比例 |
| 模型质量 | 无明显破面、错误法线和穿插 |
| 材质 | 木材、金属、玻璃、布料区分明确 |
| 纹理 | 清晰、无明显拉伸和不合理重复 |
| 光照 | 无明显过曝、严重闪烁或过黑阴影 |
| 碰撞 | 与可见模型和实际尺寸匹配 |
| 交互 | 正常选择、移动、旋转和放置 |
| 性能 | 不造成不可接受的帧率下降 |
| 存档 | 替换资源后旧存档正常读取 |
| 展示 | 总览和近景下均达到质量要求 |

## 15. 最终视觉目标

GameMemoirStore 最终应成为以现代游戏房间、电脑设备收集和桌搭布置为核心的 3D 生活模拟游戏。

玩家能够：

- 购买和升级不同风格的电脑设备
- 收集并布置家具
- 自由组合墙面、地板和材质
- 调整自然光、室内灯和 RGB
- 设计个性化桌搭
- 展示电脑配置和房间成果
- 打造独一无二的游戏空间

**最终视觉目标：**

一个具有真实空间比例、精致家具、自然光照、现代电脑设备和丰富生活装饰的温馨游戏房间。

My Dream Setup 作为空间氛围和桌搭展示方向的参考；GameMemoirStore 在此基础上突出电脑设备收集、升级、游戏经营和生活模拟特色。

### 最终设计原则

1. 正式放弃像素风格。
2. 不追求照片级写实。
3. 采用现代轻写实 3D 风格。
4. 优先保证房间整体视觉统一。
5. 重点打造电脑设备和桌搭。
6. 所有新增美术资源服务于房间布置玩法。
7. 美术升级不得破坏现有游戏系统和存档兼容性。
8. 每个阶段完成后提交 GitHub 并通过相应测试，再进入下一阶段。
