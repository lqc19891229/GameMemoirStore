# 3D 模型精细化制作规范

版本：1.1  
适用项目：GameMemoirStore / 游戏回忆录  
引擎：Godot 4.6，Compatibility 渲染器  
坐标：米制，Y 向上，模型正面 +Z  
视觉基准：现代、温馨、整洁的轻写实 3D（Stylized Realism）

## 1. 美术目标

所有新资产以现代轻写实房间为基准：轮廓可信、比例符合实际用途、结构完整、材质有区分，细节在真实游戏镜头下可读。

视觉关键词：
- Cozy：温馨、舒适、有生活气息
- Modern：现代、简洁、功能清晰
- Clean：整洁、克制、层级明确
- Stylized Realism：比例可信、适度风格化，不追求照片级写实
- Soft Lighting：柔和自然光和受控的局部装饰光
- Gaming Setup：电脑设备和桌搭是视觉重点

**不再把像素化渲染、低分辨率采样或颜色量化作为当前风格的一部分。** 历史像素资产可暂时保留，但新模型、材质和 UI 不应继续沿用像素化表现。

## 2. 资产等级与预算

| 等级 | 适用对象 | 三角面预算参考 | 制作要求 |
|---|---|---:|---|
| S | 桌子、显示器、机箱、键盘、鼠标、电竞椅 | 3,000–12,000 | 完整正侧背结构、分层零件、适度倒角、材质分区；按需预留独立发光区域 |
| A | 书架、柜子、落地灯、沙发、大型绿植 | 1,500–6,000 | 主体比例正确，至少三类可见结构细节，正侧面完整 |
| B | 水杯、手办、游戏盒、耳机、音箱、小型摆件 | 300–2,000 | 轮廓清楚，至少两类可识别细节，材质和颜色有层次 |

面数是预算参考，不是最低要求。最终以游戏实际观察距离、画面占比和性能测试为准。不可见区域不制作无意义细节；关键轮廓和近景细节优先于单纯增加面数。

## 3. 几何与结构标准

- 主要边缘根据材质、尺寸和镜头距离添加适度倒角。
- 面板、支架、连接件、按钮、桌板和装饰件应有合理厚度。
- 不允许只制作正面而忽略侧面和背面。
- 不允许直接用无倒角方块拼成最终展示资产；程序化样板几何只能作为布局、比例和材质验证阶段的占位模型。
- 不允许出现悬空零件、明显穿插、反法线或不合理连接。
- 小型结构优先使用真实几何；极细微纹理可由贴图或法线表达。
- 结构细节必须符合物品实际用途，不为装饰而堆叠无意义零件。

## 4. 重点资产结构要求

### 桌子
桌板厚度和倒角、金属桌腿、横梁、理线槽、走线孔、抽屉或收纳结构。灯带与木质主体分开，避免桌面边缘像无厚度平面。

### 显示器
屏幕开口、边框、后壳、底座、支架、倾斜连接、散热区、接口和电源状态灯。CRT 与 LCD 必须在厚度、轮廓和支架上有明显区别。游戏屏幕由 Godot 实时显示节点提供，模型不得遮挡屏幕区域。

### 电脑机箱
前面板、侧板、通风孔、I/O 接口、脚垫、内部主板、显卡、散热器和风扇。高阶型号可使用侧透玻璃与 RGB 风扇。发光环、风扇和内部组件应通过独立节点或材质分组控制。

### 键盘
独立键帽、主键区、功能键、方向键、空格键、键盘底壳、键床、指示灯和连接结构。高级款可增加旋钮、掌托、RGB 背光和材质拼接。

### 鼠标
符合人体工学的主体曲面、左右键分区、滚轮、侧键、DPI 键、传感器和脚贴。RGB 装饰不能遮挡按键结构。

### 电竞椅
坐垫、靠背、头枕、腰靠、侧翼、扶手、扶手支撑、底盘、气压杆、五星脚和滚轮。布料、塑料和金属必须具有可区分的材质表现。

### 房间家具
书架应表现层板、侧板、背板和摆件；落地灯应表现底座、灯杆、灯罩和扩散罩；地毯应表现织物厚度、包边和纹理；绿植应有自然的叶片层次和花盆结构。

## 5. 材质与纹理规范

以 Godot StandardMaterial3D / PBR 工作流为基础，按需使用 Base Color、Metallic、Roughness、Normal、Ambient Occlusion 和 Emission。

| 材质 | 视觉要求 |
|---|---|
| 木材 | 低至中等反射，木纹方向与结构一致，避免照片纹理过强 |
| 金属 | 适度金属度和清晰但不过强的高光 |
| 塑料 | 哑光或半光泽，颜色稳定，不呈现廉价湿亮感 |
| 玻璃 | 透明度、反射和厚度合理，避免整块玻璃过度发白 |
| 布料 | 高粗糙度，柔和高光，近景可加入细腻织物纹理 |
| 皮革 | 低强度纹理和柔和反射 |
| 橡胶 | 高粗糙度、低反射 |
| 发光材质 | 独立材质分组，可单独调色、调亮度和开关 |

默认使用适合连续材质的线性 / 三线性过滤与合理 mipmap。只有明确作为复古贴图或像素艺术资产时，才单独使用最近邻过滤；不得将最近邻设为现代房间的全局默认。

大面积基础色以暖白、米白、浅灰、浅橡木和低饱和绿灰为主。强调色可使用雾蓝、薄荷绿、柔和紫色和暖橙。RGB 可以更鲜艳，但必须控制亮度与照射范围。

## 6. 发光与灯光接口

- Emission 自发光材质与实际照明节点必须分开。
- 发光区域应独立于主体材质，便于运行时调色和开关。
- RGB 颜色不能平均分配到所有部件；每件资产只设置少量视觉焦点。
- 不允许仅靠自发光材质照亮整个房间。
- 实际灯光的颜色、强度、范围由 Godot 场景控制。
- 避免为每颗 RGB 灯珠创建独立动态灯光；优先使用发光材质，少量辅助 OmniLight3D 负责环境贡献。
- 房间自然光、空间灯光和设备 RGB 必须分组控制，不能互相覆盖。

## 7. 坐标、尺寸和碰撞

- 单位为米，Y 轴向上，正面为 +Z。
- 家具原点位于地面中心；电脑设备原点位于底部中心。
- 桌面设备以桌面为局部坐标基准。
- GLB 可见几何必须完全位于对应 bounds 内。
- 碰撞范围应覆盖可见几何，但不能无理由放大。
- 旋转后不得越过房间或桌面边界。
- 改动模型尺寸时，必须同步核对场景 PickArea、Resource bounds 和 LayoutEditor 占地。
- 保持现有设备 ID、场景引用、玩家存档字段和布局坐标格式兼容。

## 8. 性能规范

- 静态零件按材质合并网格。
- 需要独立控制颜色、发光、动画或开关的部件保留独立材质分组。
- 高频重复小物件共享 Mesh 与材质，必要时使用 MultiMesh。
- 避免大量运行时 MeshInstance3D、不必要的透明材质和过多实时阴影。
- 对高反射玻璃、透明材质和后处理进行单独性能采样。
- 在完整房间、常见家具数量和多设备 RGB 开启状态下进行测试。
- 以目标 PC 稳定 60 FPS 为方向，必须通过实际性能测试确认，不以静态场景推断。

## 9. Blender 到 Godot 流程

1. Blender 中完成主体、结构细节、材质和 UV。
2. 检查模型比例、坐标、原点、法线和应用变换。
3. 检查所有零件均在 bounds 内，关键结构没有穿插或悬空。
4. 导出 GLB，贴图嵌入文件，材质名称保持稳定。
5. 保留 Godot 对应的 .import sidecar 和稳定资源路径。
6. 在 Godot 4.6 Compatibility 渲染器中检查材质、透明度和发光。
7. 在游戏真实摄像机距离、总览镜头和近景镜头下检查。
8. 运行资源审计、工作台视图、布局、碰撞和存档测试。
9. 通过实际游戏画面验收后，再替换旧资产或扩展同系列模型。

## 10. 验收清单

- [ ] 主体轮廓和比例清楚。
- [ ] 结构层次完整，主要零件有厚度。
- [ ] 正面、侧面、背面均有合理细节。
- [ ] 倒角适度，无明显穿插或悬空。
- [ ] 材质区分清晰，符合现代轻写实风格。
- [ ] 纹理过滤和分辨率适合实际镜头，不默认像素化。
- [ ] 发光材质与实际照明分离。
- [ ] 模型尺寸、原点和 bounds 正确。
- [ ] 可正常移动、旋转、吸附和存档。
- [ ] 不与其他物件穿模。
- [ ] GLB 无外部依赖。
- [ ] 在 Godot 实际运行画面中验收，而不只看 Blender 视口。

## 11. 资产升级策略

先以 docs/ART_STYLE_GUIDE.md 和 docs/WORKSTATION_LAYOUT.md 定义的现代房间样板间为视觉基准。当前程序化房间壳体、桌子、书架、落地灯、地毯和绿植仅用于验证空间结构、比例、碰撞与灯光；椅子已切换为精细人体工学 GLB。其余占位模型通过视觉验收后，逐步制作正式 GLB 资产替换。

优先顺序：
1. 房间外壳与窗户
2. 桌子和椅子
3. 显示器、机箱、键盘和鼠标
4. 书架和落地灯
5. 地毯、绿植和墙面装饰
6. 其他生活家具与桌面摆件

每次替换必须保留稳定 ID、节点接口、碰撞尺寸和存档兼容。
