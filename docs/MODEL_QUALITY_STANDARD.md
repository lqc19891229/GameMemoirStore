# 3D 模型精细化制作规范

版本：1.0  
适用项目：GameMemoirStore / 游戏回忆录  
引擎：Godot 4.6，Compatibility 渲染器  
坐标：米制，Y 向上，模型正面 +Z

## 1. 美术目标

采用 Stylized 3D 与像素化渲染结合的方向：温馨游戏房、复古电脑房、现代电竞工作室。目标是让物品在游戏实际观察距离下具有清楚轮廓、合理结构、丰富但克制的细节，以及统一的材质语言。

不以单纯增加面数为目标。优先级为：

1. 主体比例和外轮廓。
2. 结构分层与厚度。
3. 二级细节和真实装配关系。
4. 材质区分与局部纹理。
5. 发光区域和灯光表现。
6. 面数、材质数和运行成本控制。

## 2. 资产等级

| 等级 | 适用对象 | 目标三角面数 | 制作要求 |
|---|---|---:|---|
| S | 桌子、显示器、机箱、键盘、鼠标、电竞椅 | 3,000–12,000 | 完整正侧背结构、分层零件、倒角、材质分区；适用时预留独立发光区域 |
| A | 书架、柜子、落地灯、沙发、大型绿植 | 1,500–6,000 | 主体比例正确，至少 3 类可见结构细节，正侧面完整 |
| B | 水杯、手办、游戏盒、耳机、音箱、小型摆件 | 300–2,000 | 轮廓清楚，至少 2 类可识别细节，材质和颜色有层次 |

面数是预算参考，不是硬性最低要求。最终以实际游戏镜头中的视觉效果为准。

## 3. 几何标准

- 主要边缘必须根据材质和比例添加适度倒角。
- 面板、支架、连接件、按钮和装饰件应具有明确厚度。
- 不允许只制作正面、忽略侧面和背面。
- 不允许用若干无倒角方块直接拼成最终展示资产。
- 不允许为不可见区域制作大量无意义细节。
- 细小结构应优先使用真实几何；极微小纹理可使用像素贴图。
- 不得出现悬空零件、明显穿插、反法线或不合理连接。

## 4. 重点资产结构要求

### 桌子
桌板厚度和倒角、桌腿、金属支撑、横梁、理线槽、走线孔、抽屉或收纳结构。灯带应独立于木质主体。

### 显示器
屏幕开口、边框、后壳、底座、支架、倾斜连接、散热区、接口和电源状态灯。CRT 与 LCD 必须在厚度、轮廓和支架上有明显区别。游戏屏幕由 Godot 实时 QuadMesh 提供，模型不得遮挡屏幕区域。

### 电脑机箱
前面板、侧板、通风孔、I/O 接口、脚垫、内部主板、显卡、散热器和风扇。高阶型号可使用侧透玻璃与 RGB 风扇。发光环、风扇和内部组件应通过独立材质分组。

### 键盘
独立键帽、主键区、功能键、方向键、空格键、键盘底壳、键床、指示灯和连接结构。高级款可增加旋钮、掌托、RGB 背光和材质拼接。

### 鼠标
符合人体工学的主体曲面、左右键分区、滚轮、侧键、DPI 键、传感器和脚贴。RGB 装饰不能遮挡按键结构。

### 电竞椅
坐垫、靠背、头枕、腰靠、侧翼、扶手、扶手支撑、底盘、气压杆、五星脚和滚轮。布料、塑料和金属必须具有可区分的材质表现。

## 5. 材质和贴图

| 材质 | 视觉要求 |
|---|---|
| 木材 | 柔和像素纹理，避免高频照片纹理 |
| 塑料 | 低至中等粗糙度，颜色稳定 |
| 金属 | 适度金属度和边缘高光 |
| 玻璃 | 低粗糙度，透明度受控 |
| 布料 | 高粗糙度，使用明暗块面表达织物 |
| 橡胶 | 高粗糙度、低反射 |
| 发光材质 | 独立材质分组，可单独调色和开关 |

默认使用最近邻采样。贴图尺寸按屏幕占比选择，不为每个模型强制制作贴图。能通过几何和材质表达的结构，不必强行使用纹理。

## 6. 发光与灯光接口

- Emissive 自发光材质与实际照明节点必须分开。
- 发光区域应独立于主体材质，便于运行时调色和开关。
- RGB 颜色不能平均分配到所有部件；每件资产最多设置少量视觉焦点。
- 不允许仅靠自发光材质照亮整个房间。
- 实际灯光的颜色、强度、范围由 Godot 场景控制。
- 后续灯光系统应支持颜色、亮度、开关和预设分组。

## 7. 坐标、尺寸和碰撞

- 单位为米，Y 轴向上，正面为 +Z。
- 家具原点位于地面中心；电脑设备原点位于底部中心。
- 桌面设备以桌面为局部坐标基准。
- GLB 可见几何必须完全位于对应 bounds 内。
- 碰撞范围应覆盖可见几何，但不能无理由放大。
- 旋转后不得越过房间或桌面边界。
- 改动模型尺寸时，必须同步核对场景 PickArea、Resource bounds 和 LayoutEditor 占地。
- 保持现有设备 ID、场景引用、玩家存档字段和布局坐标格式兼容。

## 8. 性能规范

- 静态零件按材质合并网格。
- 需要独立控制颜色、发光、动画或开关的部件保留独立材质分组。
- 避免大量运行时 MeshInstance3D。
- 避免不必要的透明材质和实时阴影。
- 高频重复小物件尽量共享 Mesh 与材质。
- 资产应能在房间同时加载时保持稳定帧率。

## 9. Blender 到 Godot 流程

1. Blender 中完成主体、细节、材质和 UV。
2. 检查模型比例、坐标、原点和法线。
3. 检查所有零件均在 bounds 内。
4. 导出 GLB，贴图嵌入文件。
5. 保留 Godot 对应的 .import sidecar。
6. 在 Godot 4.6 Compatibility 渲染器中检查材质和发光。
7. 在游戏真实摄像机距离下检查轮廓和细节。
8. 运行资源审计、工作台视图、布局和碰撞测试。

## 10. 验收清单

- [ ] 主体轮廓和比例清楚。
- [ ] 结构层次完整，主要零件有厚度。
- [ ] 正面、侧面、背面均有合理细节。
- [ ] 倒角适度，无明显穿插或悬空。
- [ ] 材质区分清晰，像素风格统一。
- [ ] 发光材质与实际照明分离。
- [ ] 模型尺寸、原点和 bounds 正确。
- [ ] 可正常移动、旋转、吸附和存档。
- [ ] 不与其他物件穿模。
- [ ] GLB 无外部依赖。
- [ ] 在 Godot 实际运行画面中验收，而不只看 Blender 视口。

## 11. 资产升级策略

先完成 docs/DESKTOP_SHOWCASE_V1.md 定义的电脑桌区域样板间。样板间通过验收后，再将同一标准推广到书架、落地灯、地毯、植物和房间装饰物。
