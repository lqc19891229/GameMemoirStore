# 房间系统六项完善工程清单

本分支用于安全落地第一批改动；尚未实现的功能不得标注为完成。
基线：Godot 4.6 / GDScript / Compatibility renderer。继续保留库存 UID、旧家具角色、交易存档和撤销/重做规则。

## 已完成的第一批改动（需要 CI 验证）

- [x] 配色预设从 9 种增加到 16 种，旧索引 0–8 及原颜色数据保持不变；场景浮动色板自动读取新增选项。
- [x] `MemoirFurnitureSupportSurfaces`：校验局部表面锚点、检测物品占地是否落在表面内、转换到世界坐标，拒绝非法值、超界以及重名锚点。
- [x] 书架（4 层）、写字桌、边桌、两种茶几、矮架的脚本运行时提供显式承载面数据。仅生成元数据，不放行原有地面碰撞规则。
- [x] 房间编辑模式增加“拍照”，在隐藏房间 HUD 后从当前渲染帧抓取 PNG，存入 `user://room_photos/`，并向玩家显示实际路径/错误。
- [x] 新增锚点与色板回归脚本，纳入房间专项 CI 工作流。

## 1. 通用表面放置（P0，尚未完整实现）

- [ ] 商品定义增加 `placement_surface=table/shelf/wall`（保持旧字段默认兼容）。
- [ ] 新增独立小型装饰物，至少覆盖桌面和书架；支持同款不同 UID。
- [ ] 在布局系统新增 `support_role` / `anchor_id` / 局部平面偏移，移动父物件时同步移动所有子物件。
- [ ] 支持墙上挂画、墙灯和门窗碰撞。
- [ ] 编辑中阻止子物件穿透、悬空以及互相重叠；取消/撤销/存盘/加载全流程验证。
- [ ] 收纳父家具时提示子物件，并确保无失联布局或丢失库存。

## 2. 自由配色与材质（P0，预设扩充已完成）

- [ ] 在现有 16 色预设之外增加 RGB/HEX 自定义值；不要将 HEX 字符串写入旧整数索引字段。
- [ ] 每个 GLB 设置稳定材质槽（木材/布料/金属/装饰），按 UID 保存局部覆写。
- [ ] 支持细节材质、颜色收藏和恢复原始材质；避免改变共享 GLB 原资源。

## 3. 家具和装饰品扩充（P0，待资源制作）

- [ ] 首批 50 个可互动或可陈列的低占地物品（书、杯子、手办、盒子、台灯、相框、盆栽等）。
- [ ] 每个资源必须有对应的独立 GLB、碰撞框、名称、售价、分类和缩略图。
- [ ] 用现有 `data/items/_catalog.tres` 接入商店/库存，继续遵循 UID 与库存限额。

## 4. 灯光与环境（P1，基础天气已经存在）

- [ ] 单独调整灯具开关、亮度、色温、RGB；在 Godot Compatibility 上控制灯光预算。
- [ ] 雪景、室外光变化、独立天气声量；保留现有 4 种天气旧索引。
- [ ] 跟随作品保存天气及灯光配置；加入摄像机/环境不同设备性能档位。

## 5. 放置与镜头体验（P1，已有直接操作）

- [ ] 小物件遮挡时支持循环选中和快速定位。
- [ ] 连续摆放同款物品、贴面预览、阻挡提示以及选中物高亮。
- [ ] 1280×800、1920×1080、2560×1440 进行实际 UI/鼠标/视角验证。
- [ ] 支持视角预设和截图构图（隐藏网格、预览辅助线和交互 HUD）。

## 6. 作品管理与分享（P2，拍照入口已实现）

- [ ] 多份带名称的独立作品存档和封面缩略图。
- [ ] 作品相册、重命名、删除、导入导出与版本兼容。
- [ ] 图片分享无需上传服务；创意工坊另开有明确权限/审核/兼容规则的阶段。
