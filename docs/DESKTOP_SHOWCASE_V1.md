# Desktop Showcase v1：电脑桌区域品质样板间

## 目标

把玩家最常观察的电脑桌区域升级为高品质像素 3D 展示区。保持现有房间结构、相机、设备 ID、存档格式和布置系统不变，只替换模型资产。

## 视觉关系

- 桌面和家具以暖木色、石墨灰、金属色为基础。
- 入门设备保留复古米色识别度。
- 进阶设备使用石墨灰、银色和少量青蓝 / 洋红 RGB。
- RGB 只强调风扇、键盘底光、鼠标装饰和桌底灯带，不把整个模型做成发光物。
- CRT 与 LCD 的轮廓差异必须明显。
- 电竞椅采用深色布料与金属底座，避免塑料方块感。

## 不改动的接口

- starter_pc、workstation、starter_monitor、lcd_monitor、starter_mouse、precise_mouse 等 ID 不变。
- 保持 data/hardware/*.tres 的资源路径、屏幕尺寸和屏幕位置。
- 保持 scenes/computer/hardware/*.tscn 的节点结构、角色和拾取逻辑。
- 保持 scenes/room/chair.tscn 的 role、bounds 和 PickArea。
- 保持 workstation_layout_data.gd 与玩家存档格式不变。
- 不改房间尺寸、桌面尺寸、设备默认位置和玩家存档迁移逻辑。

## 验收步骤

1. 运行 Blender 硬件模型生成脚本。
2. 运行 Python 房间模型生成脚本（椅子由硬件模型脚本生成）。
3. 检查 GLB 结构、材质、包围盒和外部依赖。
4. Godot 4.6 导入所有资源。
5. 运行工作台视图、布局、碰撞和房间测试。
6. 在游戏总览镜头、近距离设备镜头和不同灯光下检查。
7. 通过后再将同一品质标准扩展到其他家具。
