# 玩家调整工作台布置

在 ComputerDesktop 顶栏点击“调整布置”。单击物品或左侧列表选择桌子、机箱、显示器、键盘或鼠标；此时点击屏幕只会选中显示器，不操作系统应用。

| 操作 | 行为 |
|---|---|
| 移动 G | 拖动物品或黄色方块平移；红色手柄沿所选物品 X 轴，蓝色沿 Z 轴；碰到设备时停止 |
| 旋转 R | 拖动黄色圆点水平旋转；Q / E 或角度按钮尝试调整 15°，中途碰到设备或桌沿时停止 |
| 吸附 | 默认按 5 cm / 15° 对齐，开关可关闭 |
| 右键拖动 / 滚轮 | 环绕观察 / 缩放，不改变物品布局 |
| 应用布置 | 有效时确认布局，写入现有存档，返回总览 |
| 取消 / Esc | 恢复进入编辑前最后确认的布局 |
| 恢复默认布置 | 将草稿恢复为编辑器保存的初始布局；仍需应用才保存 |

选择“桌子”会移动或旋转整套工作台。设备使用相对桌面的坐标，键盘与鼠标各自独立。设备底部始终贴合桌面，旋转后的完整占地也必须留在桌沿内。

拖动时检查从当前位置到目标位置的整个扫掠区域，即使一帧把鼠标拖到障碍物另一侧，也会停在首次接触之前。旋转拆成不超过 1° 的小段检查扫掠区域，避免起点与终点都不重叠、但中途扫过其他物品。冲突时二分寻找最后可用位置，选中框变橙色，显示“已阻挡”及阻挡对象。最后可用位置仍可应用；碰撞限制优先于 5 cm / 15° 吸附，接触时位置或角度可以偏离吸附值。

这套桌面布置约束使用带留白的凸占地判定，不使用刚体推挤或掉落。设备不会推走其他物品。直接由其他代码写入的无效变换仍会被应用前检查拦截，红框提示修复。

## 场景与脚本

- `scenes/computer/workstation_3d.tscn`：TableGroup 下包含 Desk、DeskPickArea 和 Equipment。设备的底部原点、模型资源不变。
- `scenes/computer/ui/layout_gizmo.tscn`：已保存的选择框、平移与旋转手柄及其拾取区域；不动态生成家具模型。
- `scripts/life/workstation_layout.gd`：草稿、确认布局、手柄输入、吸附、边缘约束和占地碰撞检查。
- `scripts/life/workstation_layout_data.gd`：存档字段校验与凸多边形重叠判定。
- `computer_desktop.gd`：布置模式入口、HUD、输入分流和存档接入。

在 LayoutEditor 检查器中可调整桌面半尺寸、高度、边缘留白、桌子移动范围、吸附步长及 collision_margin。collision_margin 默认每件设备外扩 1 cm，两件设备之间留约 2 cm 安全间距（有 2 mm 接触容差）。默认桌面为 4.8×2.3 米，高 0.78 米，整套水平移动限制为中心两侧各 1.5 米。几何和这些限制应保持一致。MemoirDeviceModel.bounds 必须覆盖可见模型，包括按钮、接口、玻璃等凸出部分。

## 保存与兼容

继续使用版本 3 存档，在 `life.workstation_layout` 下保存 desk、monitor、computer、keyboard、mouse 的 `{x,z,yaw}`。desk 相对工作台场景，其余设备相对桌面组合。高度与缩放仍由场景控制，不写入玩家布局。

旧存档没有此字段时使用编辑器默认布置；读取只接受已知物品和有限数值，再按当前场景约束位置。若旧存档或型号切换导致设备占地冲突，保留桌子位置并将设备恢复为编辑器默认摆放，玩家可重新调整并应用。不自动保存拖动草稿：取消、后台自动保存或在编辑中退出，都不会把未确认的草稿写入存档。

正常运行会恢复玩家已保存的布置；`--fresh` 使用编辑器默认布置。设备始终挂在 Equipment 下，总览与屏幕操作只切换镜头，不重置已确认布局。商城、网页和运行中的应用继续共用原来的 GameSession。

## 验证

`tests/life/test_workstation_layout.gd` 覆盖真实输入拖动、轴向移动、旋转手柄、吸附开关、桌沿、重叠拦截、整套跟随、应用/取消、恢复默认、状态刷新、装备切换、屏幕往返与取景、保存读回和编辑中退出。

`tests/life/test_workstation_collision.gd` 覆盖可见模型边界、真实指针快速拖过键盘、吸附开关下的连续阻挡、接触后移开、旋转中途扫到鼠标、桌子变换后的碰撞和旧布局重叠恢复。

```bash
godot --headless --path . --script res://tests/life/test_workstation_layout.gd -- --fresh
```
