# P24 家具商店与库存一体化

家具商店和库存继续使用同一个商品 ID、库存 UID 与分类搜索。房间目录和商店库存数字来自共同的 `MemoirInventoryData.stock_summary()`，清楚列出「已拥有、可摆放、已摆放」的实例数量。

## 操作

- **在购物页浏览**：每件家具直接展示真实 GLB 模型缩略图，点击「查看 3D 大图」可展开模型预览。预览材质仍使用现有的九种风格，且不修改已拥有物品。
- **单独购买**：点击「购买」仅购入一件家具，不自动改变其颜色或进入房间，保留老流程。
- **购买并摆放**：选好预览材质，点击「购买并摆放」，只扣一次点数、创建一个新的 UID，然后直接进入房间编辑器的新家具预览。若已拥有旧的空闲副本，仍使用本次刚购买的 UID。
- **从库存摆放**：打开「我的物品」，选择空闲家具「摆放」，直接在 3D 房间编辑器中预览。选非「原色」外观时，预览颜色只应用到正在摆放的实例，不会提前写进存档。
- **查看已摆放**：如果该类家具全部已摆放，库存按钮变成「查看已摆放」，返回房间并选中一件现有家具，镜头对准它，不会修改家具位姿或存档。
- **撤销/取消**：材质与位姿在房间编辑期间属于暂存状态。取消新家具预览或取消编辑会恢复这些变更，但已经完成的购买保持拥有。只有「保存设计」才会持久化对应 UID 的外观。

电脑设备不参与地面家具快速摆放，保留「安装」与专用电脑桌限制。旧购物逻辑、存档结构和重复家具 UID 格式均未改变。

## 验证

`tests/life/test_shop_room_flow.gd` 验证购买并摆放、重复购买 UID、预览材质取消和保存、库存导航、缺钱拒绝、非家具过滤和库存数据一致性。文件已注册到完整 GitHub CI 及房间专项测试。
