# 游戏回忆录（GameMemoirStore）
## 项目开发大纲

### 一、项目定位

一款以**游戏玩家成长经历**为主题的模拟经营游戏。

玩家通过购买游戏、完成成就、升级电脑硬件和设计个人房间，逐步打造属于自己的游戏生活空间。

游戏由三个核心系统构成：

1. **房间设计**：打造个性化的游戏空间。
2. **主机硬件搭配**：购买、组装和升级电脑设备。
3. **游戏购买与成就**：收藏游戏、完成挑战并推动玩家成长。

---

### 二、核心系统与当前进度

#### 1. 房间设计

**当前状态：基础建造系统基本完成，进入内容扩充阶段。**

已实现：
- 房间尺寸、户型、墙体和门窗编辑。
- 地板、墙面、灯光和功能分区装修。
- 家具购买、摆放、旋转、复制及改色。
- 智能吸附、对齐、等距排列和碰撞检测。
- 装修方案保存、撤销与重做。

待完善：
- 扩充家具、装饰品与装修素材。
- 提升模型质量、材质、光影和天气表现。
- 优化整体装修界面与交互体验。

#### 2. 主机硬件搭配

**当前状态：基础购买与设备更换流程已实现。**

已实现：
- 电脑设备商店及购买流程。
- 显示器、机箱、键盘、鼠标等设备更换。
- 不同硬件对应的 3D 外观展示。
- 部分硬件对游戏活动收益和能力产生影响。

待完善：
- CPU、GPU、内存、硬盘等核心硬件配置。
- 硬件兼容性、性能与价格体系。
- 游戏配置需求和运行性能模拟。
- 更完整的电脑组装与升级体验。

#### 3. 游戏购买与成就完成

**当前状态：核心游戏循环已初步打通。**

已实现：
- 游戏商店、购买、下载与安装。
- 游戏库管理及游玩记录。
- 游戏挑战进度、里程碑与成就。
- 玩家能力成长系统。
- 直播、攻略制作与游戏内收入。
- 按时间推进的游戏发行和销售内容。

待完善：
- 扩充游戏数量和游戏资料。
- 丰富不同类型游戏的挑战与成就。
- 深化玩家能力、硬件性能与游戏表现的联系。
- 增加长期收藏目标和成长奖励。

---

### 三、三个系统的核心循环

**购买游戏 → 游玩并完成成就 → 获得收入与成长 → 升级电脑硬件 → 装修游戏房间 → 挑战更多游戏**

三个系统相互影响，形成持续的游戏目标。

---

### 四、项目当前阶段

**整体阶段：核心玩法原型开发后期，逐步转向内容制作与体验完善。**

| 系统 | 当前进度 | 下一步重点 |
|---|---|---|
| 房间设计 | 主要功能基本完成 | 家具资产、美术与装修内容 |
| 主机硬件搭配 | 基础流程完成 | 装机系统、硬件性能模拟 |
| 游戏购买与成就 | 核心循环初步完成 | 游戏内容、成就体系与成长深度 |

### 五、后续开发方向

**第一阶段：** 完善三个核心系统，使其形成完整、可持续的游戏循环。

**第二阶段：** 扩充家具、硬件和游戏资料，建立足够丰富的可玩内容。

**第三阶段：** 统一美术风格，完善音效、动画、交互与整体用户体验。

**最终目标：** 让玩家能够在游戏中体验从普通游戏爱好者逐渐成长为资深玩家，并拥有理想游戏房间与电脑设备的过程。
